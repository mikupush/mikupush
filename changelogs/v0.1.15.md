# v0.1.15 - 2026-11-09

## Changed

- Current and completed uploads now use a table showing file name, size, transfer speed, status, percentage progress, and creation date. Column headers remain visible while scrolling.
- File and folder icons now distinguish common file types with colors adapted to light and dark themes.
- Renamed “Archived uploads” to “Completed uploads” in English and Spanish, including the empty-list message.
- The main window now opens at 1240 × 720 pixels, with the sidebar expanded by default.

## Fixed

- Upload progress stays below 100% until completion, and transfer speed is shown only during active uploads.
- Failed and canceled uploads are no longer presented as successful transfers with sharing actions.
